# Student Management System

## Project Description
This is a basic Java project developed using Java, JDBC, and MySQL to perform CRUD (Create, Read, Update, Delete) operations for managing student records.

## Technologies Used
- Java
- JDBC
- MySQL

## Features
- Add Student
- View Students
- Update Student
- Delete Student

## Project Type
Console-based application.

## Output Screenshots
Screenshots are available inside the `outputs` folder.

## How to Run
1. Open project in IntelliJ IDEA
2. Connect MySQL database
3. Run Main.java
